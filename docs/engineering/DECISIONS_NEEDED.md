# Decisions Needed Before Public Beta

These are intentionally not guessed in the documentation pack.

## Required early decisions

- Exact supported Node, pnpm, Rust and Tauri versions (M0).
- Exact desktop auth/session strategy and callback scheme (M0/M1).
- Initial API error and pagination schema (M0/M2).
- Exact XP earning policy and anti-abuse thresholds (before M4).
- Whether NerdCoins are included in the MVP or deferred (before M4).
- Initial cosmetic catalogue and asset licensing (before M4).
- Object storage provider and upload scanning strategy (before uploads).
- Email provider and deliverability setup (before auth launch).
- Source/documentation licenses and trademark policy (before public source release).
- Privacy policy, terms, retention, export and deletion rules (before public beta).
- Supported desktop OS/version matrix and auto-update trust model (before distribution).

## Decision process

For each decision, document context, options, selected option, trade-offs and follow-up work. Use an ADR for architectural decisions. Use product docs for product policy. Record the decision in the relevant issue/PR as well.
