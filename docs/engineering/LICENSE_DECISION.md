# License Decision — Required Before Public Source Release

The product direction is open-source core, but the exact legal license has not been selected.

Maintainers must explicitly decide:

- Application source license.
- Documentation license.
- Design, icon, font and other asset licenses.
- Trademark/name policy for NerdHub.
- Contribution licensing expectations (CLA/DCO or neither).
- Whether hosted operational components are in the same repository or separately licensed.

Do not add a guessed `LICENSE` file or advertise the project as MIT, Apache-2.0, GPL or another license until this decision is approved. Review dependencies and bundled assets for compatibility. Seek qualified legal advice for commercial or trademark questions.
