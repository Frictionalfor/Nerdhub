# M1 Identity Threat Model & Mitigation Matrix

> **Milestone:** M1 — Identity and Onboarding
> **Scope:** Authentication, Credentials, Sessions, Desktop Transport, Rate Limiting
> **Last Updated:** 2026-11-09

## 1. Threat Scenarios & Mitigations

The following matrix assesses 20 distinct identity attack vectors, their severity, proposed mitigations, and required acceptance tests:

| #      | Attack Scenario                          | Severity | Proposed Mitigation                                                                                           | Missing / Additional Control                                                                                        | Verifiable Acceptance Test                                                                                                                              |
| :----- | :--------------------------------------- | :------: | :------------------------------------------------------------------------------------------------------------ | :------------------------------------------------------------------------------------------------------------------ | :------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **1**  | **Credential Stuffing**                  |   High   | Redis sliding-window rate limits by IP and account.                                                           | Automated alerting on high-velocity 401 response spikes.                                                            | Simulate 50 failed logins across 5 IPs; verify HTTP 429 lockout.                                                                                        |
| **2**  | **Brute-Force Login**                    |   High   | Generic invalid credentials error; progressive delay.                                                         | Account lock with progressive delay after 5 failed attempts.                                                        | Assert response time and status after repeated failures.                                                                                                |
| **3**  | **Password DB Theft**                    | Critical | Argon2id hashing ($m=64\text{MB}, t=3, p=1$).                                                                 | Server-side HMAC pepper configured via environment secret.                                                          | Verify database dump yields only salted PHC strings.                                                                                                    |
| **4**  | **Refresh Token Theft**                  | Critical | OS Credential Store via Tauri native keychain.                                                                | Never write tokens to `localStorage` or `IndexedDB`.                                                                | Inspect desktop renderer storage; assert zero tokens in webview storage.                                                                                |
| **5**  | **Refresh Token Replay**                 |   High   | Token family revocation upon detected reuse.                                                                  | 30s idempotency cache window; atomic row lock (`SELECT FOR UPDATE`).                                                | Replay consumed token; verify entire session family revoked with HTTP 401.                                                                              |
| **6**  | **OAuth CSRF**                           |   High   | Cryptographically random `state` parameter bound to session.                                                  | Single-use `state` with 5-minute TTL; validated before code exchange.                                               | Tamper with `state` in OAuth callback; assert HTTP 400 Bad Request.                                                                                     |
| **7**  | **OAuth Account Takeover**               | Critical | Provider `provider_subject` mapping only; auto-linking by email forbidden.                                    | Return `409 ACCOUNT_COLLISION` on matching unlinked email.                                                          | Sign in with matching email via OAuth; assert collision flow triggered.                                                                                 |
| **8**  | **Account-Linking Attack**               |   High   | Authenticated reauthentication required to link accounts.                                                     | Disallow unauthenticated linking; verify session ownership.                                                         | Attempt linking without valid bearer token; assert HTTP 401 Unauthorized.                                                                               |
| **9**  | **Email Enumeration**                    |  Medium  | Generic response messages for registration and password reset.                                                | Constant-time dummy hash verification on non-existent accounts.                                                     | Send reset requests for valid and invalid emails; assert identical response time and body.                                                              |
| **10** | **Password-Reset Abuse**                 |   High   | Single-use expiring tokens stored as SHA-256 digests.                                                         | Resetting password immediately revokes all active user sessions.                                                    | Use reset token twice; assert second attempt fails. Verify old sessions 401.                                                                            |
| **11** | **Verification Token Theft**             |   High   | Digested storage (SHA-256); single-use transaction; 24h TTL.                                                  | Token marked consumed in database transaction upon redemption.                                                      | Query `auth_tokens` table; verify raw token is not stored.                                                                                              |
| **12** | **Session Fixation**                     |   High   | Regenerate session identifier and family on authentication.                                                   | Invalidate pre-auth session state; issue fresh `family_id` on login.                                                | Verify session ID changes before and after authentication.                                                                                              |
| **13** | **Desktop Deep-Link Interception**       |   High   | One-time completion code exchanged with memory-bound PKCE verifier $V$.                                       | Completion code expires in 60s; single-use redemption enforced.                                                     | Intercept completion code; attempt exchange without $V$; assert HTTP 400 error.                                                                         |
| **14** | **Renderer Process Compromise**          |   High   | Least-privilege Tauri IPC bridge with zero filesystem/shell permissions.                                      | Audit `tauri.conf.json` and capability manifests.                                                                   | Attempt unauthorized IPC calls from webview; verify invocation rejection.                                                                               |
| **15** | **Rate Limit Bypass**                    |  Medium  | Multi-keyed Redis counters (`IP + Route` and `AccountHash + Route`).                                          | Fail closed on Redis failure for sensitive abuse-control routes.                                                    | Rotate `X-Forwarded-For`; verify account-level rate limit still triggers.                                                                               |
| **16** | **Sensitive Info in Logs**               |   High   | Structured Pino redaction on headers, passwords, and tokens.                                                  | Redaction keys configured for `authorization`, `password`, `token`.                                                 | Grep test log output; assert zero matches for plaintext tokens or credentials.                                                                          |
| **17** | **Desktop Binary Secrets**               | Critical | Server-side OAuth exchange; zero provider secrets in client.                                                  | Automated CI scan on compiled desktop binary.                                                                       | Run `strings` on compiled desktop binary; assert zero OAuth client secrets found.                                                                       |
| **18** | **Account Creation Race Condition**      |  Medium  | PostgreSQL unique constraints on `email` and `handle`.                                                        | Catch Postgres `23505` error; translate to clean conflict response.                                                 | Concurrently fire 10 identical registrations; assert exactly 1 succeeds, 9 fail safely.                                                                 |
| **19** | **Concurrent Refresh & Logout**          |  Medium  | Database row lock on session during revocation.                                                               | Atomically update `revoked_at`; abort concurrent refresh cleanly.                                                   | Fire refresh and logout simultaneously; verify session is definitively revoked.                                                                         |
| **20** | **DB Failure on Token Rotation**         |   High   | Transactional rollback ensures old token remains valid on DB failure.                                         | Atomic transaction (`consume + issue`); rollback on error.                                                          | Inject error during token update; assert old token remains valid for retry.                                                                             |
| **21** | **Redis Outage Session Revocation**      | Critical | Fail-closed for writes/sensitive ops; degraded read-only only on approved endpoints; max exposure 15m.        | Fail-closed allow-list; degraded-read-only logging + alerting; auto-recovery.                                       | Stop Redis; assert writes & sensitive ops rejected; assert approved read-only works without sensitive data; assert warn log + `redis_unavailable=true`. |
| **22** | **Refresh Token Idempotency Cache Leak** |   High   | Cached rotation responses encrypted with authenticated encryption; key never stored with ciphertext; 30s TTL. | AES-256-GCM cache encryption; dedicated key rotated every 90 days.                                                  | Inspect cache storage; assert no plaintext refresh token; assert 30s expiry; assert key not co-located with ciphertext.                                 |
| **23** | **Session Cap Eviction**                 |   High   | Max 5 active sessions; oldest evicted deterministically and atomically; user notified.                        | Deterministic ordering (`created_at`, `session_id` tie-break); transactional eviction+creation; session-out notice. | Create 6 sessions; assert oldest evicted and user notified; assert concurrency caps at 5; assert already-revoked sessions not counted.                  |
